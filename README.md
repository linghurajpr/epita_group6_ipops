## 1. Project Overview

**Geolocation & IP Ops** is a Python-based application developed by EPITA Group 6 as part of the Engineering Tools TP2 assignment.

The application integrates the IPInfo API to retrieve geolocation and network information associated with public IPv4 and IPv6 addresses.

It provides a foundation for IP address lookup, geographical identification, network information retrieval, API error handling and command-line interaction.

The project uses the IPInfo Legacy API endpoint specified in the assignment.

## 2. Project Objectives

- Retrieve information about the machine's public IP address.
- Perform IP lookups using IPv4 and IPv6 addresses.
- Identify geographical information associated with an IP address.
- Retrieve city, region and country information.
- Retrieve geographical coordinates.
- Identify network organizations and ISP information.
- Retrieve postal code and timezone information.
- Implement secure API authentication.
- Handle invalid inputs and API errors.
- Provide a Python command-line interface.
